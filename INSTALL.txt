EuropaVR - first person VR mod for Europa
=========================================

REQUIREMENTS
------------
  * Europa on Steam (any recent version)
  * A PC VR headset with an OpenXR runtime (SteamVR, Oculus/Meta, Virtual Desktop...)
  * Windows 10/11, 64-bit

  Nothing else to download. UEVR is included.


INSTALL
-------
  1. Close the game.

  2. Copy the "Europa" folder from this archive into your Europa install
     directory, merging it with the one already there:

         ...\steamapps\common\Europa\

     If you did it right, this file now exists:

         ...\steamapps\common\Europa\Europa\Binaries\Win64\dsound.dll

     To find the folder: Steam -> right click Europa -> Manage -> Browse local files.

  3. Put your headset on and launch Europa normally from Steam.

That is all. There is no injector to run and nothing to click. The game starts
flat, then switches to VR by itself a few seconds after the window appears.


CONTROLS
--------
  Left stick          move, relative to where you are looking
  Right stick         turn (snap by default)
  Right stick click   pause menu
  Insert  or L3+R3    open the UEVR menu (settings, camera offsets)

Everything else keeps the game's own gamepad mapping.


TUNING
------
  Everything is in one file:

      Europa\Binaries\Win64\EuropaVR\EuropaVR.ini

  The top half is read at startup - VR runtime, timings, resolution, FSR,
  anti-aliasing. Lower ScreenPercentage first if the framerate struggles: try 85,
  then 75.

  The bottom half is re-read about once a second, so those edits apply while the
  game is running - eye placement, turning, pause button, the in-game book.
  If the character turns the opposite way to your head, set YawSign=1.

  UEVR menu -> Camera Offset
      Nudge the eye position live, in the headset.


UNINSTALL
---------
  Delete these two, and the game is exactly as it was:

      Europa\Binaries\Win64\dsound.dll
      Europa\Binaries\Win64\EuropaVR\        (whole folder)

  The mod also writes outside the game folder. One of those is worth cleaning up:

      %LOCALAPPDATA%\Europa\Saved\Config\WindowsNoEditor\Engine.ini

  It gains an [Audio] section, which does nothing without the mod, and a
  [SystemSettings] section holding r.ScreenPercentage=100 and FSR off. That
  second one KEEPS APPLYING to the flat game - it would run at full resolution
  instead of the 65% it ships with, so it will be heavier than it was. Delete
  both sections to put it back exactly as it was.

  This one is genuinely inert without the mod and can be left alone:
      %APPDATA%\UnrealVRMod\Europa-Win64-Shipping\   (VR settings)


IF IT DOES NOT WORK
-------------------
  The loader writes a log next to itself:

      Europa\Binaries\Win64\EuropaVR\EuropaVR.log

  It records every step, so it will say where things stopped.

  * Game starts flat and stays flat
        Check the log. Make sure your VR runtime is running first.

  * Game crashes on launch
        UEVR is loading too early. Raise PostWindowDelayMs in EuropaVR.ini
        (try 15000). Enabled=0 disables the mod entirely without uninstalling.

  * SteamVR shows the game in its desktop theatre, asking you to "Resume game"
        Expected. Steam hands the game SteamVR's OpenXR runtime, SteamVR sees a
        flat app, and the mod only turns it into a VR app a few seconds later.
        Dismiss it once. UseSystemOpenXrRuntime=1 avoids it by using your own
        OpenXR runtime instead - a real change of runtime, so only if you want it.

  * No sound once VR starts
        Should be handled automatically. If not, check that SteamVR is not
        switching your default audio device away from where you are listening.
